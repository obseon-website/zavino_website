# Zavino redesign research — AI-first brief

Updated **4 October 2026**. This directory is the design and content handoff for a later website build. **This research pass changes documentation only.** The live code and its current visuals are not the specification for the next build.

## Read this first

Zavino should lead as an **AI automation agency that also builds SaaS products and serious web platforms**. The target work is connected, high-value business systems: customer and operational data flowing into decisions, approved actions, and measurable outcomes. The first screen must make that value clear. AI UGC creative, custom AI, marketing, content, branding, SEO, and other web work remain available, but they should enter after the core offer is understood or through a relevant buyer journey.

The goal is to become a leading AI automation agency; the site must express ambition through the quality of its thinking and execution, **without claiming an unverified rank, enterprise client history, ROI, security certification, or case-study result**. A large company should be able to recognize that Zavino understands integration, permissions, review gates, operations, and product delivery. A visitor should be able to tell what to discuss next without deciphering a motion demo.

## Non-negotiable handoff rules

1. Build the homepage around **AI automation and SaaS development**. Make web development the third visible capability, with its full breadth explained on its own page.
2. Use a real business workflow as the signature visual: **customer signal → connected data → AI-assisted decision → human approval → offer/action → measurement**. Label it as an illustrative Zavino concept until it is a documented engagement.
3. Show off frontend ability with custom, purposeful, glowing CSS motion and exceptionally good responsive composition. The site must still read clearly as a static page, on touch, and with reduced motion.
4. Keep all source-linked NeuroXAI research available. Carry over its useful **problem → scope → deliverables → process → proof → brief/booking** structure; do not copy its prices, guarantees, client claims, wording, or page count as Zavino facts.
5. Do not let existing creative reels imply AI or SaaS delivery. Label real creative work by its actual role and label in-house product/automation demos as concepts.
6. Before writing code in a future pass, read the relevant installed Next.js guide in node_modules/next/dist/docs/ as required by AGENTS.md.

The future builder should treat this as an invitation to deliver its **strongest frontend design and motion work**, while holding every visual choice to the buyer's need for clarity, trust, and a useful next action.
